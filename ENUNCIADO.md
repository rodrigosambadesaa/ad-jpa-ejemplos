# Material de partida — Ejemplos JPA

El archivo original recuperado de Google Drive (`EjemplosJPA.zip`) contiene **dos ejemplos didácticos de persistencia con JPA**, no un boletín con un enunciado independiente:

1. un dominio de **empleados y departamentos**;
2. un dominio de **profesores y correos electrónicos**.

El objetivo del material es mostrar el mapeo objeto-relacional de entidades y relaciones, la configuración de una unidad de persistencia y operaciones básicas de persistencia/consulta.

La versión de este repositorio conserva ambos dominios utilizando Jakarta Persistence y Hibernate actuales.

> No se ha localizado junto al ZIP un PDF de enunciado específico. Por ello este archivo identifica de forma explícita el material de partida sin presentar como literal un enunciado que no existe.
